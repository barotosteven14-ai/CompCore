CHECK BEFORE BUYING

Compatibility Guide

Always check these connections before purchasing your computer components.

⚠️

CPU ↔ Motherboard

Check if the CPU socket is supported.

⚠️

Motherboard ↔ RAM

Check RAM generation and motherboard support.

⚠️

GPU ↔ Case

Check the GPU length and case clearance.

⚠️

Cooler ↔ CPU

Check CPU socket compatibility.

⚠️

Cooler ↔ Case

Check CPU cooler height or radiator space.

⚠️

PSU ↔ Components

Check power requirements and connectors.

⚠️

Motherboard ↔ Case

Check the motherboard form factor.

⚠️

Storage ↔ Motherboard

Check available SATA or M.2 slots.

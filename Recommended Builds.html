UNDERSTAND YOUR BUILD

Why This Build?

Every component should have a purpose and work well with the other components.

CPU + GPU

These components should be reasonably balanced for the games and applications you plan to use.

Motherboard

The motherboard provides compatibility and connection between the major components.

RAM + Storage

Enough RAM supports multitasking while fast storage helps with loading programs and files.

Cooling + Case

Proper cooling and airflow help keep temperatures under control.

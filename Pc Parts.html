LEARN THE COMPONENTS

PC Parts Guide

Learn what each computer component does and why it is important when building a PC.

01

CPU

The CPU or Central Processing Unit is the main processor of the computer. It handles instructions and performs calculations needed by programs and games.

Main Function

Processes instructions and controls many of the computer's tasks.

Important Specifications

  • Number of cores
  • Number of threads
  • Clock speed
  • CPU socket
  • Power consumption

Effect on Performance

A stronger CPU can improve gaming performance, multitasking, productivity, and applications that depend heavily on the processor.

Common Beginner Mistake

Choosing a CPU without checking whether the motherboard has the correct socket.

02

GPU

The GPU or Graphics Processing Unit is responsible for rendering images, videos, games, and other graphics.

Main Function

Processes and displays graphics on the monitor.

Important "Specifications

  • VRAM
  • GPU performance
  • Power consumption
  • GPU size
  • Display outputs

Effect on Performance

The GPU has a major effect on gaming performance, especially at higher resolutions and graphics settings.

Common Beginner Mistake

Buying a powerful GPU without checking if it fits inside the PC case or works well with the CPU.

03

Motherboard

The motherboard is the main circuit board that connects the CPU, RAM, storage, GPU, and other components together.

Main Function

Allows the different PC components to communicate and work together.

Important Specifications

  • CPU socket
  • Chipset
  • RAM support
  • M.2 slots
  • PCIe slots
  • Form factor

Effect on Performance

The motherboard determines which components can be installed and what features and upgrade options are available.

Common Beginner Mistake

Choosing a motherboard without checking CPU, RAM, and case compatibility.

04

RAM

RAM or Random Access Memory temporarily stores data that the computer is currently using.

Main Function

Provides fast temporary storage for active programs and tasks.

Important Specifications

  • Capacity
  • RAM generation
  • Speed
  • Latency
  • Number of modules

Effect on Performance

Having enough RAM helps with multitasking, gaming, schoolwork, and demanding applications.

Common Beginner Mistake

Buying RAM that is not supported by the motherboard.

05

Storage

Storage is where the operating system, applications, games, documents, photos, and other files are saved.

Main Function

Permanently stores files and programs.

Important Specifications

  • Storage capacity
  • Read speed
  • Write speed
  • SSD or HDD
  • M.2 compatibility

Effect on Performance

Faster storage can reduce operating system startup times and improve application and game loading times.

Common Beginner Mistake

Buying an M.2 SSD without checking if the motherboard has a compatible M.2 slot.

06

PSU

The PSU or Power Supply Unit provides electricity to all of the computer's components.

Main Function

Converts electricity from the wall outlet into power that the computer can use.

Important Specifications

  • Wattage
  • Efficiency rating
  • Connectors
  • PSU form factor
  • Build quality

Effect on Performance

A reliable PSU helps provide stable and safe power to the entire system.

Common Beginner Mistake

Choosing a PSU based only on wattage instead of considering quality and system requirements.

07

CPU Cooler

The CPU cooler removes heat produced by the processor while the computer is running.

Main Function

Keeps the CPU at safe operating temperatures.

Important Specifications

  • Cooling capacity
  • Socket compatibility
  • Cooler height
  • Radiator size
  • Fan size

Effect on Performance

Good cooling helps prevent excessive heat and can help the CPU maintain stable performance.

Common Beginner Mistake

Choosing a cooler that does not fit the CPU socket or PC case.

08

PC Case

The PC case houses and protects the internal components of the computer.

Main Function

Provides physical space and protection for computer components.

Important Specifications

  • Motherboard support
  • GPU clearance
  • CPU cooler clearance
  • Fan support
  • Airflow

Effect on Performance

A well-designed case can improve airflow and cooling while making installation easier.

Common Beginner Mistake

Buying a case that is too small for the GPU, motherboard, or CPU cooler.

09

Case Fans

Case fans move air through the PC case to help remove warm air and bring in cooler air.

Main Function

Improves airflow and helps cool the internal components.

Important Specifications

  • Fan size
  • Airflow
  • Fan speed
  • Noise level
  • Connector type

Effect on Performance

Good airflow can help keep the CPU and GPU temperatures under control.

Common Beginner Mistake

Installing fans without considering the direction of airflow.
